# ENGINEERING CONSULTANCY - AGENT GUIDELINES (V2 - UTOPIA/BRUTALIST)

## 1. CORE PHILOSOPHY & VIBE
You are acting as a Lead Technical Architect creating a web experience that fuses high-end Engineering with an "Industrial Techno-Brutalist" aesthetic.
* **The Goal:** Professional, capable, and secure, but visually bold, raw, and energetic. Think "Engineered Chaos" or "Digital Utopia built on monolithic code."
* **NOT Allowed:** Clean corporate minimalism, soft shadows, rounded corners, stock photos of offices, gentle gradients.
* **Tone:** Authoritative, confident, slightly aggressive, technical.

## 2. VISUAL DESIGN SYSTEM (The "Utopia" Aesthetic)
Strictly adhere to these principles to achieve the desired atmosphere:

* **Theme & Texture (Utopia/TLOP):**
    * Base: Deep, textured darks (`#050505`, `#0F0F0F`). Use subtle background textures: film grain, CRT scanlines, concrete noise, dark circuit board patterns.
    * Lighting: Dramatic, high-contrast lighting. Elements should feel illuminated by harsh spotlights or screen glow.
* **Color Palette (Graduation Energy):**
    * Strict monochrome base for structure.
    * **Accents must be RADIOACTIVE:** Use hyper-saturated neon for interactions (hover states, buttons, key data). Electric Volt (`#CEFF00`), Cyber Magenta (`#FF00FF`), Laser Blue (`#00F0FF`).
* **Typography (TLOP Influence):**
    * Headlines: MASSIVE, bold, wide sans-serif fonts (e.g., Archivo Black, Monument Extended). Don't be afraid to overlap text or let it bleed off the screen edge. Use repetitive text elements for emphasis.
    * Technical Details: Strictly **Monospace** (Fira Code, JetBrains Mono) for anything related to code, data, or subtitles.
* **UI Components (Industrial):**
    * **Brutalist structure:** Thick borders (2px-4px), exposed grids, visible layout lines.
    * **NO Border Radius:** Everything must be sharp squares or rectangles (`border-radius: 0px`).
    * **Imagery:** Abstract technical visualizations rendered raw: point clouds, wireframe meshes, glitch art representations of security concepts.

## 3. INTERACTION & BEHAVIOR (Fun yet Pro)
* **Hover States:** Interactions should be explosive. Instant color changes, aggressive glitches, or rapid shifts in position. Make the user want to click.
* **Scrolling:** Use parallax effects where layered elements move at different speeds to create depth in the "digital ruins."

## 4. CONTENT STRUCTURE
* Focus on the 3 pillars: Web Engineering, Automation, Cybersecurity.
* Present them not as "services" but as "System Modules" or "Infrastructure Components."
